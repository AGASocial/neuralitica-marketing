V1 default stack

Low tier

  • LLM hub: SiliconFlow (DeepSeek + Qwen)
  • TTS: CosyVoice2
  • Avatar: SadTalker (Replicate)
  • Avatar alt: MuseTalk (generic loop)
  • B-roll: Wan2.1 I2V Turbo
  • Assembly: FFmpeg on server
  • Fallback: manual upload (US-8.3)

~$1.10 – $1.75 / client / week

Stories: US-X.4, US-8.2, US-8.5, US-8.6, US-9.3

Premium / P1

High tier

  • LLM: OpenAI / Anthropic frontier
  • TTS: ElevenLabs
  • Avatar: HeyGen (US-8.7)
  • B-roll: LTX 2.3 Pro / Kling 3.0
  • QA: optional vision pass on final MP4

~$8 – $12 / client / week

Use for paid upsell or operator override — not V1 silent default.

Upgrade order

When to move up a tier

  1. Avatar adapter (SadTalker → MuseTalk → HeyGen)
  2. B-roll adapter (Wan → Hailuo → LTX/Kling)
  3. TTS provider
  4. LLM provider (last — smallest cost impact)

Risks

Chinese / budget provider checklist

  • Verify commercial license and likeness handling before routing client photos through any vendor.
  • API keys stay server-only — never NEXT_PUBLIC_*, never in catalog rows.
  • Download-and-own all provider outputs; never persist raw vendor URLs long-term.
  • Keep HeyGen or manual upload as operator escape hatch (US-8.7, US-8.3).
