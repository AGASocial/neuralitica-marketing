Agente Video-First Económico

Roadmap actualizado para una V1 enfocada en Instagram, prestadores locales y producción de videos sin exigir que el cliente grabe. La prioridad es reducir costo por pieza usando avatar, voz IA, plantillas, subtítulos y proveedores intercambiables.

Qué hay que construir realmente

La V1 no debe depender de text-to-video completo para cada Reel. El sistema debe producir videos baratos combinando avatar o talking-head, voz IA, subtítulos, plantillas 9:16, covers simples y B-roll generado solo cuando aporte valor.

Regla central: no generar todo desde cero si una plantilla, un avatar reutilizable y buen guion resuelven el objetivo comercial.
Nueva decisión de producto

El cliente no graba

  • Puede usar avatar propio autorizado.
  • Puede usar avatar genérico profesional.
  • Puede usar video sin rostro con voz, texto, stock o B-roll IA.
  • Solo responde entrevista, entrega datos y aprueba contenido.

Regla de producto

No meter de más

  • No multicanal en V1.
  • No ads para validar.
  • No dashboard complejo.
  • No generación cara por defecto.
Criterio económico clave

API barata primero; self-host después

Para 1 a 10 clientes, conviene validar con APIs o servicios externos baratos. Self-hosting con GPU solo debe considerarse cuando exista volumen, porque open source no significa costo cero: implica GPU, colas, mantenimiento, fallos y soporte técnico.

EtapaRecomendaciónRazón
1-10 clientesAPI externa barataValidar rápido sin montar infraestructura pesada.
10-50 clientesAPI + pruebas self-hostMedir costo real y estabilidad antes de migrar.
50+ clientesEvaluar self-host parcialProteger margen en generación repetitiva.
100+ clientesPipeline propia optimizadaAutomatizar colas, costos, fallos y calidad.

Detalle por módulo

Qué hace cada pieza

Interview Builder

P0Input

Formulario o entrevista guiada para capturar servicios, zona, tono, ofertas, objeciones, estilo y restricciones.

Salida: respuestas estructuradas del cliente.

Business Profile

P0Core data

Ficha viva del negocio que alimenta todos los agentes y evita rehacer preguntas cada semana.

Salida: perfil canónico del cliente.

Avatar / Visual Mode Selector

P0Rules

Permite elegir avatar propio autorizado, avatar genérico o video sin rostro, con reglas de consentimiento y representación.

Salida: modo visual activo + restricciones.

Cost Policy Engine

P0Economics

Define el proveedor recomendado por pieza según duración, costo máximo, calidad mínima, avatar requerido y necesidad de B-roll.

Salida: decisión de proveedor y presupuesto estimado.

Content Strategy Agent

P0Planning

Genera pilares, temas y secuencia semanal orientados a confianza, educación, venta local y mensajes entrantes.

Salida: brief semanal de contenido.

Video Script Agent

P0Generation

Convierte la estrategia en guiones breves, hooks, CTAs, voz en off y texto en pantalla para cada Reel.

Salida: paquete de scripts por pieza.

Caption Agent

P0Copy

Genera captions, hashtags, keywords locales y variantes de CTA alineadas con el Reel.

Salida: copy listo para revisión.

Video Provider Adapter

P0Integration

Conecta con proveedores externos o self-hosted sin acoplar el producto a uno solo.

Salida: job de video, estado, costo y asset resultante.

Media Assembly Pipeline

P0Assembly

Ensambla voz, avatar/B-roll, subtítulos, logo, cover y formato 9:16 en un video publicable.

Salida: Reel final o preview.

QA/Compliance Agent

P0Validation

Revisa claims peligrosos, tono, claridad, disclosure IA, uso correcto de avatar y coherencia con reglas V1.

Salida: aprobación interna o flags de corrección.

Approval Flow

P0Delivery

Presenta el contenido al cliente para aprobar, rechazar o pedir una ronda controlada de cambios.

Salida: estado de aprobación por pieza.

Content Calendar

P1Ops

Ordena la semana: qué pieza va qué día, qué falta aprobar y qué está listo para publicación manual.

Salida: calendario operativo semanal.

Metrics Lite

P1Feedback

Guarda métricas simples: reproducciones, likes, comentarios, guardados, mensajes y temas que funcionaron.

Salida: señales para el siguiente ciclo.

Riesgos principales

Lo que puede dañar margen o confianza

  • Usar text-to-video caro para cada pieza.
  • No controlar regeneraciones fallidas.
  • Fingir que un avatar genérico es el dueño real.
  • Publicar sin aprobación.
  • No medir costo real por Reel.
  • Elegir self-hosting antes de tener volumen.
Reglas duras V1

Criterios de producto

  1. No exigir grabación humana.
  2. 3 Reels IA semanales como base.
  3. Avatar propio solo con consentimiento explícito.
  4. Avatar genérico no debe hacerse pasar por el dueño.
  5. Proveedor de video intercambiable desde el diseño.
  6. Presupuesto máximo por Reel antes de generar.
  7. Aprobación del cliente antes de publicar.
  8. Instagram primero; multicanal después.

Fuentes y validación

Notas de precios y modelos

Los precios de proveedores cambian. Este roadmap usa los costos como criterio de diseño, no como garantía contractual. Antes de cerrar pricing comercial, validar precios vigentes, límites, licencias, uso comercial y condiciones de cada proveedor.

  • LTX: API de video por segundo para text-to-video/image-to-video.
  • HeyGen: API de avatar por minuto para validación rápida.
  • MuseTalk: opción open source para lip-sync con uso comercial permitido según su repositorio.
  • RunPod: referencia de GPU cloud para evaluar self-hosting cuando exista volumen.
Documento actualizado con criterio V1: Instagram video-first, sin grabación humana obligatoria, costo bajo por pieza, proveedores intercambiables y validación API primero/self-host después.
