# High-Level Plan

# Informe Breve — V1 Sistema Agéntico de Marketing Local Video-First

## 1. Concepto

La V1 será un **sistema agéntico de marketing para Instagram**, enfocado en prestadores de servicios locales como plomeros, peluqueros, barberos, electricistas, técnicos de aire acondicionado, manicuristas y similares.

El objetivo es que el cliente pueda delegar la creación de contenido para redes sin tener que pensar ideas, escribir textos ni grabarse en video.

## 2. Promesa principal

> El cliente responde una entrevista inicial, aprueba el contenido y el sistema genera videos, captions, stories y CTAs para Instagram usando avatar propio autorizado, avatar genérico o videos sin rostro.

## 3. Enfoque de V1

La V1 será **video-first** y se enfocará inicialmente en Instagram.

No se busca construir todavía un sistema multicanal completo. El foco será producir contenido útil y frecuente para atraer confianza, mensajes y potenciales clientes.

## 4. Problema que resuelve

Los prestadores de servicios locales suelen tener estos problemas:

* No saben qué publicar.
* No tienen tiempo para redes.
* No quieren grabarse.
* No saben escribir buenos captions.
* No tienen estrategia de contenido.
* Publican de forma irregular.
* No convierten redes en conversaciones comerciales.

El sistema reduce esa fricción al producir contenido listo para revisar y publicar.

## 5. Modos de video

### 5.1 Avatar propio autorizado

El cliente autoriza el uso de su imagen para crear videos con un avatar basado en él.

**Ventaja:** mayor confianza y marca personal.
**Requisito:** consentimiento explícito y control del uso de imagen.

### 5.2 Avatar genérico profesional

El sistema usa un avatar genérico acorde al oficio: plomero, barbero, técnico, estilista, etc.

**Ventaja:** rápido, escalable y no exige que el cliente se grabe.
**Regla:** no debe fingir ser el dueño real del negocio.

### 5.3 Video sin rostro

El sistema genera videos con imágenes, animaciones, herramientas, texto en pantalla, voz IA, stock o escenas generadas.

**Ventaja:** más simple, seguro y escalable.

## 6. Flujo operativo V1

```text
Entrevista inicial
→ Ficha viva del negocio
→ Selección de modo visual
→ Estrategia semanal de Instagram
→ Ideas de Reels
→ Guiones + hooks + CTAs
→ Generación de videos IA
→ Captions + hashtags + covers
→ QA automático
→ Aprobación del cliente
→ Publicación manual asistida
→ Métricas básicas
→ Aprendizaje para la siguiente semana
```

## 7. Entregables semanales sugeridos

| Entregable             | Cantidad V1 |
| ---------------------- | ----------: |
| Reels generados por IA |           3 |
| Stories                |           5 |
| Captions               |           3 |
| Hooks alternativos     |  2 por Reel |
| CTAs                   | 1 por pieza |
| Hashtags/keywords      |          Sí |
| Covers simples         |          Sí |
| Brief visual           |          Sí |
| Reporte de aprendizaje |     Mensual |

La V1 debe estar preparada para escalar luego a **5 Reels semanales**, pero el MVP debe iniciar con 3 para mantener simplicidad operativa.

## 9. Reglas duras de V1

1. No exigir que el cliente grabe videos.
2. No publicar sin aprobación.
3. No usar avatar propio sin consentimiento explícito.
4. No hacer pasar un avatar genérico como si fuera el dueño real.
5. No prometer resultados garantizados.
6. No generar claims técnicos peligrosos sin revisión.
7. No automatizar respuestas sensibles por DM en V1.
8. No construir multicanal todavía.
9. No depender de ads para validar.
10. Mantener la operación simple y vendible.

## 10. Alcance excluido en V1

La V1 no incluye:

* TikTok.
* YouTube.
* LinkedIn.
* Blog.
* Ads.
* CRM avanzado.
* Dashboard complejo.
* Publicación automática obligatoria.
* Automatización completa de DMs.
* Edición avanzada propietaria de video.

## 11. Posicionamiento comercial

### Versión corta

> Tu agente de marketing crea Reels, Stories y publicaciones para Instagram sin que tengas que grabarte, pensar ideas ni escribir textos.

### Versión para prestador local

> Respondes una entrevista, apruebas el contenido y tu Instagram empieza a publicar videos útiles para que más personas te escriban cuando necesiten tus servicios.

## 12. Dirección recomendada

La V1 debe ser:

> **Agente Instagram video-first para prestadores locales, capaz de generar 3 Reels semanales usando avatar propio autorizado, avatar genérico o videos sin rostro, sin exigir que el cliente grabe contenido.**

El producto debe venderse como una forma de quitarle al prestador local la carga de redes sociales, no como una herramienta técnica compleja.

## 13. Norte posterior

Después de validar V1, el sistema puede evolucionar hacia:

1. 5 Reels semanales.
2. Publicación automática.
3. Integración con WhatsApp.
4. Google Business Profile.
5. TikTok.
6. Reportes avanzados.
7. Ads locales.
8. CRM ligero.
9. Respuestas asistidas por IA.
10. Sistema multicanal completo.

## 14. Conclusión

La mejor V1 no es un SaaS completo ni una plataforma omnicanal. Es un sistema enfocado, claro y vendible:

> **Crear videos para Instagram de forma automática o semi-automática para prestadores de servicios locales que no quieren grabarse ni gestionar redes.**

Esto ataca una fricción real: falta de tiempo, falta de ideas, incomodidad frente a cámara y baja constancia.
